# Feedback Management System

A simple Feedback Management System built using **ASP.NET Core and C#**. It allows users to submit feedback, provide a rating, and view submitted feedback.

## Features

- Submit feedback using a form
- Enter name and email address
- Give a rating from 1 to 5
- Validate user input
- View all submitted feedback
- Simple and responsive user interface

## Technologies Used

- C#
- ASP.NET Core
- HTML
- CSS

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/krishnapopat130324-art/Feedback-Management-System.git
   ```

2. Open the project folder:

   ```bash
   cd Feedback-Management-System
   ```

3. Run the application:

   ```bash
   dotnet run
   ```

4. Open the local URL displayed in the terminal in your browser.

## Data Storage

Feedback is stored temporarily in memory. The submitted data is cleared when the application restarts.
